# 减脂饮食记录

手机、电脑都能用的饮食记录网页：记每天吃了什么，对照热量、蛋白质、碳水、脂肪、膳食纤维的目标看还差多少，支持多个用户，并且能让 ChatGPT 或 Claude 直接读写记录、给建议。

**网址：https://zhengma-cyber.github.io/diet-tracker/**

不用登录、不用安装。手机上打开后可以「添加到主屏幕」，当 App 用。

## 怎么用

### 记一笔

1. 顶部选日期（默认今天），选早餐 / 午餐 / 晚餐 / 加餐。
2. 搜食物，比如「鸡腿」「big mac」「火车头」，从下拉里选。
3. 填克数（食材按生重）或份数（外卖按份），点「添加」。
4. 上面的大数字立刻更新：今天还能吃多少 kcal，四项营养素各还差多少，以及换算成具体食物的提示（如「蛋白质还差 67 g ≈ 鸡胸肉 280 g」）。

食物库内置 160 多种：家常食材按每 100 g，麦当劳、Chipotle、Subway、Sweetgreen、Chick-fil-A、越南粉等外卖按每份。没有的食物点「新建食物」自己加，之后所有人都能搜到。

「常吃」一栏会自动列出你最近记过的食物，点一下直接选中。

### 目标设置

右上角「目标设置」：

- 填性别、年龄、身高、体重、活动量，选减脂 / 维持 / 增肌，点「推算每日目标」会自动算出热量和五项营养素（Mifflin-St Jeor 公式），可以再手动改。
- 页面顶部会显示你的基础代谢和每日消耗。

### 多个用户

右上角用户下拉框可以切换或「添加用户」。每个人有自己的身体数据、目标和记录，自定义食物共用。

### 多设备共用一份数据

数据默认只存在当前浏览器。要手机电脑共用，或和家人共用：

- 已经接入的人在「目标设置 → 多设备同步」里点「复制邀请链接」，把链接发给你。
- 你打开链接，页面会自动接入同一份数据，然后新建一个自己的用户即可。

之后用普通网址打开也是同步的。

## 让 AI 读写记录

### 方式一：MCP 连接器（推荐，普通对话里直接用）

这个项目部署了一个 MCP 服务，ChatGPT 和 Claude 都能把它当连接器接入，之后在任何对话里说一句话就能读写：

- 「看看王小颖今天吃了什么」
- 「给马小正晚餐加一份火车头」
- 「马小正这两周吃得怎么样，给他留条建议」（建议会显示在网页上）

连接器网址里带口令，不公开，**向仓库主人索取**。拿到后：

**ChatGPT**：Settings → Connectors → Advanced 打开 Developer mode → Create → 名称随意，MCP Server URL 粘贴网址，Authentication 选 No authentication → Create。对话里点「+」勾上它，或直接提问。

**Claude（网页 / 手机 App）**：Settings → Connectors → Add custom connector → 粘贴网址 → Add。

连接器提供的工具：

| 工具 | 作用 |
|---|---|
| list_users | 用户列表 |
| get_nutrition_day | 某人某天：目标、已吃、还差、每条记录、建议 |
| get_nutrition_history | 某人最近 N 天的合计和食物清单 |
| add_food_entry | 加一条记录 |
| delete_food_entry | 删一条记录 |
| set_targets | 改目标 |
| leave_advice | 给某天留建议，网页显示 |

用户名直接用中文名，日期按美东时间，不说日期就是今天。

### 方式二：复制给任何 AI（只读）

页面「AI 建议」区点「复制数据给 AI」，会把目标、今天每一餐和最近 7 天汇总整理成一段文字，粘到 ChatGPT 或 Claude 里问建议即可，不需要任何设置。

### 方式三：拍照记录

把食物照片发给已接入连接器的 ChatGPT，说「这是午餐，记到王小颖」，它会估算营养并写进记录。

## 同步到 Apple Health（iPhone）

用 iPhone 自带的「快捷指令」App 建一个名为「同步饮食到健康」的快捷指令：从服务接口取当天的热量、蛋白质、碳水、脂肪、纤维，用「记录健康样本」写入健康 App。建好后可以设成每晚自动运行；在 iPhone 上打开网站，汇总卡片下方有「同步这天到 Apple Health」按钮，可手动同步任意一天。接口网址和逐步搭建说明向仓库主人索取。

## 数据与隐私

- 记录保存在一个 Supabase 数据库里，本仓库只有打包后的网页，不含任何密钥或个人数据。
- 邀请链接和连接器网址里都带有访问凭证，拿到的人就能读写这份数据，只分享给信得过的人。
- 外卖的营养值取自各家公开菜单的常见配置，是估算；自己做的菜按食材生重计算更准。
